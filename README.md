# ⚡ Dulam Anvesh Goud | AI & ML Engineer Portfolio

A premium, highly polished software engineering portfolio built with a **"Clean Modernism" (21st.dev / Vercel-inspired) aesthetic**. This site focuses entirely on high-end typography, smooth micro-interactions, and cinematic scroll architecture to showcase expertise in Artificial Intelligence, Machine Learning, Prompt Engineering, and Software Development.

## ✨ Key Features
* **Cinematic Full-Page Scroll:** A desktop-first `scroll-snap` architecture that rigidly snaps projects into full-screen `100vh` sections for an immersive presentation, gracefully degrading to a standard vertical scroll on mobile devices.
* **Dynamic Workflow Diagrams:** The JavaScript engine analyzes each project's data and automatically renders a beautiful, layered visual flow-chart representing the "User Journey" or "System Architecture" for that specific project.
* **Premium Micro-Interactions:** Features a pure black background with subtle, CSS-driven "breathing" radial spotlights, alongside custom JavaScript-powered mouse-tracking glow effects across all glassmorphic cards.
* **Data-Driven Architecture:** All skills, categories, projects, and architectural workflows are rendered entirely dynamically from a single `data.js` configuration file, making updates instant and code-free.
* **Zero Dependencies:** Built entirely with Vanilla web technologies. No heavy frameworks, no bloated libraries—just clean, lightning-fast code.

## 🛠️ Tech Stack
* **Frontend:** Semantic HTML5, Vanilla CSS3 (with CSS Variables & Glassmorphism)
* **Logic Engine:** Vanilla JavaScript (ES6+) & Intersection Observer API
* **Architecture:** Full-page Vertical Scroll-Snap with Dynamic DOM injection
* **Typography:** Inter (Google Fonts)

## 📁 Project Structure
```text
📦 portfolio-website
 ┣ 📜 index.html    # Main semantic HTML structure and metadata
 ┣ 📜 style.css     # Clean Modernism styling, scroll-snap physics, and animations
 ┣ 📜 script.js     # Intersection observers, mouse-tracking glow, and UI rendering
 ┣ 📜 data.js       # Centralized JSON-like data layer for projects and workflows
 ┗ 📜 README.md     # You are here
```

## 🚀 How to Run Locally
Because this project utilizes a zero-dependency architecture, there is no build step or `npm install` required!
1. Simply double-click `index.html` to open it in your browser.
2. *(Optional)* For a cleaner local experience, use a basic local server: `python -m http.server 8000`
